## Hook

```
目の前で ドアが閉まる 差は ゼロコンマ
ガラスに映った 顔 だいぶ へこんだ
七千円 出して 楽を 買うか
二時間 歩いて 明日に 回すか

乗り越した分なら 機械が 精算
乗り越えられない夜は 誰が 精算
足が出る前に 足が出た
今夜の取り分 二時間の 領収書
```

## Verse

```
二次会 三次会 誘ってくる 先輩
「まだいける」 断れないのが 限界
会計は 一円単位で 割り勘
一円は 割れても 一秒は 間に合わん

改札の外 空車のランプ 六台
乗った瞬間 回り出す メーターと 後悔
スマホの残高 なんだかんだで 四桁
七千 抜いたら 明日から 三桁

百円のコーヒー 手のひらの 湯たんぽ
レシートは 丸めず 折って ポケットに しまう
コインランドリーだけが 起きてる 真夜中
変わらない 時速四キロ 俺の 歩幅

一時間 歩くと 足の裏が 喋り出す
「なあ 七千円 そんなに 惜しかったか」
惜しくはない 精算できるのは 勘定
ポケットに 残るのは レシートと 感情
```

## Hook（反復）

同文。ただし Verse で「一円単位で割り勘」を通したあとなので、
「今夜の取り分」が *割り勘の取り分* と重なって聞こえる。

## 1. 中心の仕掛け

| ID | 小節 | 種類 | 仕込み | 落とし |
