## 目的と原則

この文書は、日本語ラップの韻を検索・判定・生成する前に、文字列を比較可能な
音韻表現へ変換するための仕様である。日本語の文字数、かな数、ローマ字数を
そのまま韻長として扱わない。基本単位にはモーラを用いる。

次の表現を分離して保持する。

1. 原文表記
2. Unicode正規化後の表記
3. 形態素解析器が返す読み
4. 辞書上の発音形
5. 基底モーラ列
6. 文脈依存の実現候補
7. 演者が明示した発音

発音変異を不可逆に一つへ潰さない。特に長母音化、母音無声化、縮約、英語との
コードスイッチは候補列と信頼度で表現する。

## 証拠格付け

| 等級 | 根拠 | 実装での扱い |
|---|---|---|
| A | 査読論文、国立国語研究所等の一次資料、公式辞書仕様 | 既定規則の根拠にできる |
| B | 公式OSS/API文書、学術機関の技術文書 | 実装契約、変換例、フォールバックに使う |
| C | 大会予稿、学位論文、技術ブログ | 初期値・例外候補として使い、A/Bと区別する |
| D | 商用韻検索サイト、個人記事、出典不明の解説 | 発見用途に限定し、規則の根拠にしない |

一つの資料から日本語ラップ全体の美学を決めない。話者、方言、年代、楽曲、
テンポによる変異を明示する。

## 内部表現

推奨する1モーラの表現:

```json
{
  "surface": "キョ",
  "onset": ["k", "j"],
  "nucleus": "o",
  "special": null,
  "devoiced": false,
  "source_span": [0, 2],
  "confidence": 1.0
}
```

特殊モーラは次のように保持する。

```json
{"surface":"ン","onset":[],"nucleus":null,"special":"N"}
{"surface":"ッ","onset":[],"nucleus":null,"special":"Q"}
{"surface":"ー","onset":[],"nucleus":"o","special":"R","long_partner":3}
```

`R`は直前母音と同じ音質を持つ長音の後半モーラとして扱う。韻判定では、
母音音質だけを比べるモードと、N/Q/Rを含むモーラタイミングを厳密に比べる
モードを分ける。

## モーラ分割

日本語では、軽音節は通常1モーラ、重音節は自立モーラに特殊モーラが加わる。
次を既定値とする。

| 表記 | 分割 | モーラ数 | 注記 |
|---|---|---:|---|
| カ | ka | 1 | 通常のCV |
| ア | a | 1 | 母音のみ |
| キャ | kya | 1 | 拗音。小書きャを独立させない |
| キヤ | ki + ya | 2 | 大書きヤは独立 |
| カン | ka + N | 2 | 撥音は独立モーラ |
| カッ | ka + Q | 2 | 促音は独立モーラ |
| カー | ka + R | 2 | 長音後半も独立モーラ |
| ガッコー | ga + Q + ko + R | 4 | 「学校」の一般的発音形 |

句読点、空白、改行、`pau`、`sil`はモーラに数えない。ただし、句末・小節末・
休止位置は韻の知覚的重要度に使えるため、境界情報として別に保存する。

基礎的なモーラ・重音節の根拠には国立国語研究所の久保薗資料
（[A1](https://repository.ninjal.ac.jp/record/568/files/review000302.pdf)）、
日本音声学会誌の音節構造研究
（[A2](https://www.jstage.jst.go.jp/article/phonstud/27/0/27_61/_pdf)）を使う。

## 長音・連母音

かな表記と通常発音は一致しないことがある。一般的な実現候補として、次を
生成する。

| 表記列 | 基底候補 | 通常発音候補 |
|---|---|---|
| ああ | a + a | a + R |
| いい | i + i | i + R |
| うう | u + u | u + R |
| ええ | e + e | e + R |
| えい | e + i | e + R |
| おお | o + o | o + R |
| おう | o + u | o + R |

「映画」は通常発話で `e-R-ga` に近づき得る一方、意図的な発音、歌唱、語呂、
英語との掛け合わせでは `e-i-ga` を残し得る。したがって次を守る。

- `えい`を常に`えー`へ、`おう`を常に`おー`へ置換しない。
- 辞書の`pron`と`pronBase`、G2P出力、演者指定を候補として併存させる。
- 長音候補でのみ韻が成立する場合は、結果にその条件を表示する。
- 同じ母音音質でも、厳密モードでは `o+R` と短い`o`を同一視しない。

長母音正規化の実装例は
[C1](https://www.t4.cii.isct.ac.jp/sites/default/files/2025-05/R06_gaku_24IDH.pdf)
を参照する。ただし、この資料の正規化表を演者の唯一の発音規則にはしない。

## 撥音・促音

### 撥音 N

撥音「ン」は後続音によって両唇、歯茎、軟口蓋、口蓋垂等に実現が変わるが、
韻律上のモーラ`N`を保持する。単なる母音欠落やワイルドカードにしない。

- `カンドー`: `ka + N + do + R`
- `ハンノー`: `ha + N + no + R`

母音列だけなら両者は近く、Nを含む厳密モーラ列でも対応する。一方、
`N`と通常母音の置換は完全一致より大きく減点する。

### 促音 Q

促音「ッ」は後続子音の閉鎖・摩擦の延長として実現する。Open JTalk系の
音素出力では`cl`となる。`ッ`を無音として削除しない。

- `タッグ`: `ta + Q + gu`
- `バッグ`: `ba + Q + gu`

Qの後に有効な子音がない句末促音、連続する小書きッ、装飾的な「ッッ」は
演技的表記である可能性が高い。自動補正せず警告と代替候補を返す。

## 拗音・外来語音

最長一致で解析する。最低限、次の系列を一つの自立モーラとして扱う。

- キャ、キュ、キョ等のイ段＋小書きャュョ
- ティ、ディ、トゥ、ドゥ
- ファ、フィ、フェ、フォ
- ウィ、ウェ、ウォ
- ヴァ、ヴィ、ヴ、ヴェ、ヴォ
- シェ、ジェ、チェ
- ツァ、ツィ、ツェ、ツォ

ただし、表記と実発音に揺れがある。たとえば「ヴァ」が常に/v a/になるとは
限らず、話者によって/b a/に近づく。辞書、G2P、実演指定を別候補にする。

外来語や英字列は次の三種類を区別する。

1. 日本語化した発音: `ゲーム` → `ge + R + mu`
2. アルファベット読み: `AI` → `e + R + a + i`等
3. 原語に近いコードスイッチ発音

英語のCMU発音辞書を日本語モーラ列へ無条件に適用しない。言語spanと発音指定を
持たせ、英語spanは必要に応じて別の音素類似度で採点した後、日本語側の拍位置と
統合する。

## 母音無声化

東京方言では高母音/i, u/が、典型的に無声阻害音の間、または無声阻害音の後で
休止の前に無声化しやすい。しかし、語境界、韻律、強調、速度、話者、地域に
よって変わる。

実装規則:

- 基底表現から/i, u/を削除しない。
- `devoiced=true`の実現候補を追加する。
- Open JTalkの大文字`I`, `U`を「母音なし」ではなく「無声化母音」と読む。
- 無声化を仮定したときだけ成立する韻には減点と警告を付ける。
- 実際の録音・演者指定がある場合に限り、そのdelivery-specific表現を優先する。
- 「無声子音に挟まれる」という局所条件だけで確定しない。

査読研究では、無声化が韻律境界等に左右されること
（[A3](https://shotam.github.io/LING712_prosody_papers/KilbournCeron_2018.pdf)）、
全国608名・41都道府県で地域・世代差があること
（[A4](https://www.jstage.jst.go.jp/article/nihongonokenkyu/3/1/3_KJ00004622260/_pdf)）、
無声化/u/が完全な舌目標を持つ場合とtargetlessになる場合があること
（[A5](https://bpb-us-w2.wpmucdn.com/campuspress.yale.edu/dist/e/1695/files/2021/11/Shaw_Kawahara_2021_phonetica.pdf)）
が示されている。無声化を一律の文字削除にしない根拠である。

## 表記と実際の発音

次のケースは辞書出力を絶対視しない。

- 同形異音語: 生、上手、今日等
- 助詞: は、へ、を
- 人名、地名、芸名、当て字
- 数字、小数、日付、単位、英数字混在
- スラング、方言、ネット語、略語
- 語中の記号、ハッシュタグ、絵文字
- 意図的な旧仮名、誤字、ルビ風表記

形態素ごとに`source`, `is_oov`, `confidence`を記録する。複数バックエンドが
一致しても、人名や当て字を自動的に高信頼へ昇格させない。

## ラップ固有の発音変形

ラップでは、辞書形から次の変形が起きる。

- 縮約: `している`→`してる`
- 口語化: `わからない`→`わかんない`
- 引用表現: `という`→`っていう`
- 母音延長、語末引き伸ばし
- 母音挿入・脱落
- 英語的または方言的アクセント
- 小節境界をまたぐ連結、休止、スタッカート

これらを「誤り」として直さない。生成時は自然な候補として明示的に選び、
分析時は録音またはユーザーの読み指定がなければ複数候補にする。

ピッチアクセントは音素一致とは別特徴にする。川原の概説ではピッチ輪郭が
韻を知覚させる合図になり得る
（[C2](https://user.keio.ac.jp/~kawahara/pdf/rap2017.pdf)）が、
アクセント型の一致だけで韻を成立させない。

## 実装規則

推奨処理順:

1. 原文を保存する。
2. Unicode NFKCで比較用表記を作る。ただし原文へ上書きしない。
3. 行、小節、句読点、休止の境界を保存する。
4. 形態素解析から読み・発音形・品詞・OOV情報を得る。
5. 最長一致のかなパーサーで基底モーラ列を作る。
6. N/Q/R、拗音、外来語音を明示する。
7. 長母音、無声化、縮約の実現候補を生成する。
8. 複数G2Pの不一致を警告する。
9. ユーザー指定発音があれば最優先する。
10. 各候補に出典、変換理由、信頼度を付ける。

優先順位:

```text
行単位の演者指定
> ユーザー辞書
> 現代話し言葉UniDicのpron
> 現代書き言葉UniDic
> Sudachi Full
> pyopenjtalkによる推定
> 文字規則だけの推定
```

## 必須テスト

| 分類 | 最低限のfixture |
|---|---|
| 拗音 | キャ/キヤ、シュ/シユ、ティ/テイ |
| 特殊モーラ | 新聞、学校、東京、タッグ |
| 長母音 | 映画、成功、遠い、ゲーム |
| 無声化 | 好き、靴、です、お菓子 |
| 助詞 | 私は、東京へ、夢を |
| 口語 | してる、わかんない、っていう |
| OOV | 芸名、当て字、架空の商品名 |
| 混在 | AI、HIPHOP、game、数字＋単位 |
| 不正表記 | 先頭ー、句末ッ、連続小書き文字 |

テストは基底列だけでなく、候補数、候補種別、信頼度、警告も検証する。
